# Archive — Superseded & Completed Specs

This folder contains specs that have been implemented, superseded, or completed.
They are kept for historical reference only.

## Finding Things

- **Active specs** are in `../Active/`
- **Review cycles** are in `../../Reviews/Cycles/`
- Each archived file includes a reason for archiving (see Kieran's classification in DOC-REORG-KIERAN-REVIEW.md)

## Convention

When a spec is implemented and verified, the implementing agent moves it from `../Active/` to this folder.
Add a one-line note at the top of the file explaining what superseded it, if applicable.

## Archived by Category

| Category | Files | Status |
|----------|-------|--------|
| Completed hotfixes | HOTFIX-001, HOTFIX-002 | Fixed and merged |
| Completed fix specs | FIX-001-delete-topic (superseded by DIAG-001), REFACTOR-001 | Incorporated or superseded |
| Superseded features | FEAT-002 (→PARKED), FEAT-004 (→hybrid final), FEAT-005-talk-mode (parked) | Evolved or parked |
| Completed phases | PHASE-4-UI, MVP-COMPLETION, P2-POLISH | Phase done |
| Architecture decisions | BECHAT-CHANNEL-PLUGIN, SIMPLIFIED-CLAWCHAT-PATH, TEAM-CONSENSUS | Decision recorded, implemented differently |
| Unread indicator v1 | UNREAD-INDICATOR-SPEC (→v2) | Superseded by v2 |
| Earlier iterations | SPECS/ folder contents (scroll-bounce, jump-to-latest, etc.) | Superseded by final specs in Active/ |
